# Cyber Assistant — Character Sprites

Assets extracted from the character sheet supplied for the Cyber Assistant project.

## Categories

- idle — 6 frames
- expressions — 14 frames
- listening — 3 frames
- thinking — 3 frames
- speaking — 7 frames
- working — 6 frames
- alert — 3 frames
- sleep — 4 frames
- walk — 7 frames

Each category contains individual PNG frames and a category spritesheet.

## Important

The source image is a generated character sheet. The extraction keeps the supplied artwork/design and removes the checkerboard background where detected.

The `speaking` frames can be cycled while TTS is playing. `idle`, `thinking`, `listening`, `working`, `alert`, `sleep`, and `walk` can be connected to the assistant's state machine.

See `manifest.json` for frame counts, canvas sizes, and suggested FPS.
